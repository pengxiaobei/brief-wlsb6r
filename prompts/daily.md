# 日更：今天 5 条

读者是一个普通上班族，通勤路上在手机上看，只愿意花 1 分钟。全程用中文。

## 第一步：确认日期

```bash
date "+%Y年%m月%d日"
date "+%A"
date "+%Y-%m-%d"
```

## 第二步：搜集素材

用 WebSearch 搜过去 24 小时的信息，覆盖这三类，**就这三类，不要加别的**：

1. **在聊**（`talk`）—— 大家正在讨论、讨论度高的事
2. **影响你**（`you`）—— 会实际影响普通人生活的：政策、油价、天气台风、调休、物价、社保
3. **科技**（`tech`）—— AI 和新科技的重要进展

搜索词自己调整，参考：`今日 热搜 热点 新闻 <今天日期>`、`国内 政策 油价 天气 <今天日期>`、`AI 新模型 发布 <本月>`、`world news top stories <today>`。

也可以 WebFetch `https://rebang.today/home?tab=douyin` 和 `https://rebang.today/home?tab=weibo` 看实时热榜——这两个能正常读取。**tophub.today 会返回 403，别浪费时间试。**

## 第三步：挑正好 5 条

配比大致「在聊」2 条、「影响你」1-2 条、「科技」1-2 条，按当天实际情况浮动。

挑选标准是**读者看了会不会改变判断或行动**，不是转发量。宁可少报一个热闹的，也不要漏掉一个真影响他的。

### 这几类一律不要选，没有例外

- **严肃时政**：中美博弈、外交表态、领导人活动、国际制裁反制、战争动态
- **社会舆论纷争**：谁举报谁、司法争议、网络骂战
- **恶性刑事案件**：拐卖、凶杀、性侵
- **资本市场动态**：公司上市/IPO、发行价、市盈率、估值、融资轮次、股价涨跌、机构持仓
- 明星八卦

关于资本市场那条多说一句：读者不炒股，这些对他没有任何可执行的价值。
一家公司上市本身不是「新鲜事」，**它做的东西才是**——如果某个产品或技术确实值得说，
就直接讲那个产品，不要从上市、估值、融资的角度切入。

判断方法：如果这条新闻**读者读完除了情绪波动之外没有任何可用信息**，就不要选。「油价涨了 5 毛」他明天加油用得上，「某国对某国表态」他用不上。

素材不够就把「科技」或「在聊」多选一条补上，**不要为了凑 5 条去拿上面这些**。

## 第四步：写

每条：一句话标题（不超过 20 字）+ 正文 2-4 句。

**文风铁律，最重要的部分：**

- **必须大白话。** 读者明确说过正式表述「很多其实看不懂」。
- 任何术语必须就地翻译。反面例子：写「形式化证明」不行，要写成「证明写成了机器能一条条核验的格式，所以不存在蒙对」。写「环比下降 11%」不行，要写成「比上个月少了一成」。
- 不许出现新闻腔：据悉、值得关注、业内人士表示、引发热议、持续发酵。
- **正文里绝对不放链接。** 读者是为了省时间才看简报的——这是他明确提的要求。

## 第五步：写 today.json

在仓库根目录写 `today.json`：

```json
{
  "date": "2026年8月6日 星期四 · 上面 1 分钟，下面 5 分钟",
  "stamp": "2026-08-06",
  "note": "「今天」五条为 8 月 6 日。",
  "items": [
    {"kind": "talk", "title": "一句话标题", "body": "正文 2-4 句。"}
  ],
  "sources": [
    {"name": "来源名", "url": "https://..."}
  ]
}
```

- `kind` 只能是 `talk` / `you` / `tech`
- `date` 结尾那句「· 上面 1 分钟，下面 5 分钟」保留不变
- `stamp` 用 `YYYY-MM-DD`，存档文件名靠它
- `sources` 放你实际用到的来源，5-10 个即可

## 第六步：生成页面

```bash
python3 build.py
```

它会把 `today.json` 和 `weekly.html` 灌进 `template.html`，生成 `index.html` 和 `archive/<stamp>.html`。

**不要手改 `index.html`、`template.html`、`weekly.html`、`watchlist.json`。** 前两个改了会破坏排版，后两个归周更任务管。

脚本报错就把错误原样贴出来，不要绕过它去手写 HTML。

## 第七步：提交推送

```bash
git add -A
git -c user.name=daily-brief -c user.email=bot@example.com commit -m "日更 <stamp>"
git push origin HEAD:main
```

## 最后报告

1. 推送成功还是失败（失败贴原始错误）
2. 你选的 5 条标题，各自标了什么 kind
3. 有没有哪条你拿不准该不该选
